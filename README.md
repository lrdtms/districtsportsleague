# District Sport League website

The website for [District Sport League](https://districtsportsleague.co.za), a women-led, impact-driven company in South Africa offering corporate team building, communication development, wellness initiatives and sport-based training, with a focus on netball and female athlete empowerment.

**Live site:** https://districtsportsleague.co.za

## What's on the site
- About the company and its mission
- Latest news and outreach articles (for example the Netball in a Box visits)
- Partners and supporters
- Video content

## Tech
Plain HTML, CSS and JavaScript. No framework and no build step. A `CNAME` file points the repository's hosting at the custom domain.

## Structure
```
index.html     Home page
styles.css     Styling
script.js      Interactivity
Articles/      News and outreach articles
Partners/      Partner logos and pages
Images/        Site images
Videos/        Video content
CNAME          Custom domain
```

## Running locally
Open `index.html` in a browser, or serve the folder with any static file server.
